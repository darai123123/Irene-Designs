# Irene Designs website

Responsive static website made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile menu, current year and demo contact form
- `assets/favicon.svg` — browser tab icon

## Before publishing
1. In `script.js`, replace `hello@example.com` with your real business email.
2. Update service descriptions and business details so they accurately describe what you offer.
3. Keep the portfolio projects labelled as concepts until you have real client work.
4. Test the website on desktop and mobile.

## Preview locally
Double-click `index.html` to open it in your browser. No build tools are required.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com.
2. Create a **public** repository named `irene-designs-website`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment. The Pages section will show your website URL, usually `https://YOUR-USERNAME.github.io/irene-designs-website/`.
7. Open that URL and test the website.

## Important
- A custom domain is not required to begin.
- The contact form is a `mailto:` demo, not a hosted message service. It opens the visitor's email app after you replace the placeholder email. For a production form, connect a form service or backend.
- Google Fonts requires internet access; fallback fonts are included.
